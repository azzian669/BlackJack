# Console Blackjack Simulation ♠️

### Description
A text-based implementation of the classic casino game **Blackjack**, developed to demonstrate mastery of fundamental programming logic and state management. The user plays against an automated "Dealer" bot that follows standard casino rules.

### Key Features
* **Smart Dealer Logic:** The dealer automatically calculates moves based on standard rules (e.g., hit on soft 16, stand on 17).
* **Dynamic Deck System:** Simulates a real card deck with randomization to ensure fair probability in every draw.
* **Betting Mechanics:** Users can place virtual bets, tracking wins and losses across multiple rounds.
* **Win/Loss Evaluation:** Algorithms to instantly determine the winner based on card values, including "Bust" and "Blackjack" scenarios.

### Tech Stack
* **Language:** C / C++ (Sesuaikan dengan bahasanya)
* **Core Concepts:** Arrays, Pointers, Conditional Logic, Random Number Generation (RNG).
